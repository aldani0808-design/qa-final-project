# QA Engineering Final Project | Портфолио тестировщика

Проект по анализу требований, разработке тестовой документации и заведению дефектов.

## 📁 Структура и документы

Все материалы проекта расположены в папке [docs](./docs):

- 📄 [Вопросы к требованиям (`requirements_questions.md`)](./docs/requirements_questions.md) — анализ требований и выявление серых зон.
- 📄 [Чек-лист (`cheklist.md`)](./docs/cheklist.md) — проверки функционала регистрации.
- 📄 [Тест-кейсы (`test_cases.md`)](./docs/test_cases.md) — детальные сценарии тестирования.
- 📄 [Баг-репорты (`bug_report_template.md`)](./docs/bug_report_template.md) — отчеты о найденных дефектах.

## 🛠 Навыки и инструменты

- **Тест-дизайн:** Техники граничных значений, эквивалентное разделение, создание чек-листов и тест-кейсов.
- **Работа с дефектами:** Составление понятных и воспроизводимых баг-репортов.
- **Инструменты:** Git, GitHub Desktop, Markdown, Chrome DevTools.
