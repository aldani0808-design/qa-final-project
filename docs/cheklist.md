# Чек-лист тестирования модуля Registration

## 1. Позитивные проверки (Positive Tests)
- [ ] Успешная регистрация с валидными данными (Имя, Фамилия, уникальный Email, пароль от 8 символов)
- [ ] Отправка письма с подтверждением на указанный Email после успешной регистрации
- [ ] Автоматическое удаление пробелов в начале и конце поля Email (trimming)

## 2. Негативные проверки (Negative Tests)
- [ ] Попытка регистрации с пустыми обязательными полями
- [ ] Попытка регистрации с уже зарегистрированным Email
- [ ] Валидация формата Email (ввод email без @, без доменной части и т.д.)
- [ ] Ввод короткого пароля (менее 8 символов)
- [ ] Попытка входа в аккаунт до подтверждения почты по ссылке из письма

## 3. Граничные значения и интерфейс
- [ ] Проверка максимальной длины полей Имя и Фамилия
- [ ] Проверка ограничения частоты запросов (Rate Limiting) при частой отправке формы
