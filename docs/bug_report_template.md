# Bug Report: Некорректное отображение верстки в каталоге товаров

**ID:** BUG-001  
**Title:** Смещение элементов UI и неверные изображения при авторизации под visual_user  
**Severity:** Medium  
**Priority:** Medium  
**Environment:** macOS, Chrome (SauceDemo v1.0)  

### Preconditions:
Пользователь находится на странице авторизации https://www.saucedemo.com/.

### Steps to Reproduce:
1. Ввести в поле Username значение visual_user.
2. Ввести в поле Password значение secret_sauce.
3. Нажмите кнопку Login.
4. Осмотреть главную страницу каталога товаров /inventory.html.

### Expected Result:
Карточки товаров отображаются ровно, кнопки выравнены по сетке, изображения соответствуют наименованию товаров.

### Actual Result:
Изображения товаров отображаются с искажениями/смещением, кнопки действий расположены некорректно относительно текста.
